MAYAR CV MAKER — Version 1
==========================

FILES
- index.html: the complete website. It works as a single file and uses no external libraries.

TEST ON YOUR PHONE
1. Download and extract Mayar_CV_Maker.zip, or save index.html.
2. Open index.html using a browser such as Chrome. If your file manager does not open it correctly, use the online publishing steps below.
3. Enter information; the preview updates automatically.
4. Choose a template and optionally select a photo.
5. Tap "Print / Save PDF". In the print dialog choose "Save as PDF" if available.

PUBLISH ONLINE (simple option: GitHub Pages)
1. In Chrome, open https://github.com and create/sign into an account.
2. Create a new public repository named: mayar-cv-maker
3. Choose "Add file" > "Upload files" and upload index.html from this folder.
4. Commit/save the uploaded file.
5. Open repository Settings > Pages.
6. Under Build and deployment, choose "Deploy from a branch"; choose branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish. The website address will look like:
   https://YOUR-USERNAME.github.io/mayar-cv-maker/
   Replace YOUR-USERNAME with your GitHub username.
8. Open that link on your phone and test form, photo, templates, and print-to-PDF.

NOTES
- This version does not upload or store CV details on a server. The selected photo is held temporarily in the browser page.
- The PDF action opens the browser print dialog; choose Save as PDF. On some Android browsers the wording/options may differ.
- For a public business site, add a privacy notice and contact details before promoting it.
- Do not ask users to enter passwords, OTP codes, or other account credentials.
